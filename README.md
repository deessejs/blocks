# DeesseJS Blocks

Official DeesseJS blocks are maintained in this repository.

Each directory at the repository root contains one provider-specific block, its `deesse-block.json` descriptor, and the files that the Deesse CLI can copy into a project.

Blocks are source artifacts. They do not need to be npm packages; package manifests inside a block describe packages created in the receiving project.
